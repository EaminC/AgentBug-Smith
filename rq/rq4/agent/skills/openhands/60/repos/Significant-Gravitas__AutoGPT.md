
---\n# Typical Issue Shape\nA typical issue in this repository involves AI commands that fail to execute on specific operating systems, resulting in improper command syntax. Examples include failing to create directories or download files because the shell commands used do not account for differences between Windows and Linux environments.\n---
---\n# Recurring Fix Patterns\nCommon fixes include modifying AI commands to differentiate between operating systems and employing conditional statements to handle OS-specific behaviors. Developers often use debugging logs and validation checks to ensure commands will execute correctly in real environments.\n---
---\n# Files / Modules That Change Most Often\nThe primary files that change frequently are those in the 'autogpt' directory focusing on AI command configuration, such as 'ai_config.py', as well as the scripts handling shell commands. Test files also undergo regular updates to adapt to changing command structures and anticipated user issues.\n---
---\n# Pitfalls\nKey pitfalls to look out for include neglecting the differences between command line interfaces on different operating systems, which can lead to runtime errors. Additionally, assuming that AI commands will always behave the same across environments can result in unexpected failures during execution.\n---
---\n# Test Conventions\nTest conventions in this repository involve using unittest or pytest for file structure validations and command syntax correctness. Tests should cover different OS scenarios to ensure universal compatibility. Additionally, tests should validate that the AI correctly handles various command line requests according to the given environment.\n---
