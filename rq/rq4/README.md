# RQ4

Multi-component research repo. Each component lives under `agent/` and is
bootstrapped by its own setup script.

## Components

| # | Name | Install | Setup |
|---|------|---------|-------|
| 1 | mini-swe-agent | `git clone` + `pip install -e` | [`scripts/setup.sh`](scripts/setup.sh) |
| 2 | openhands (CLI) | `curl -fsSL https://install.openhands.dev/install.sh \| sh` | [`scripts/setup-openhands.sh`](scripts/setup-openhands.sh) |
| 3 | utils (data) | `pip install openai>=1.0` | [`scripts/setup-utils.sh`](scripts/setup-utils.sh) |

All components route their LLM calls through a shared OpenAI-compatible
gateway (`https://api.tu-zi.com`).

## Quick start (one-shot, fresh box)

```bash
git clone https://github.com/1123qqa/ICLR2027.git && cd ICLR2027
bash scripts/setup-all.sh     # runs all 3 component setup scripts
```

`setup-all.sh` checks git / python / uv / docker, ensures the daemon
is up with ≥30 GB free, then chains `setup.sh`, `setup-openhands.sh`
and `setup-utils.sh`. It is idempotent — re-run any time.

## Quick start (per-component, if you only need one)

```bash
# Component 1 — CLI agent
bash scripts/setup.sh
bash agent/run_mini.sh -t "<your task>" -m openai/gpt-4o-mini

# Component 2 — Web UI on http://localhost:8000
bash scripts/setup-openhands.sh
bash agent/run_openhands.sh
# then open http://localhost:8000 and configure LLM via Settings

# Component 3 — data pipeline (download → classify → split → train → verify)
bash scripts/setup-utils.sh
source agent/.venv/bin/activate && source utils/.env
python utils/pipeline.py                          # dataset prep
bash utils/train/run_all.sh                       # train 6 skills
python utils/verify/build_verify.py --audit       # build verify pool
```
