# Issue #237: [Bug]: Is It possible to make type hints for `response.metadata`?

**Describe the bug**
I'm trying the werewolf demo, the type of `response.metadata.xxx` is not stable. For prompt `"eliminate": "whether to eliminate a player or not (true/false)"`, it sometimes returns bool `true/false`, sometimes returns str `"true"/"false"`

**To Reproduce**
exactly the same as [agentscope](https://github.com/modelscope/agentscope/tree/main)/[examples](https://github.com/modelscope/agentscope/tree/main/examples)/[game_werewolf](https://github.com/modelscope/agentscope/tree/main/examples/game_werewolf)

**Expected behavior**
expect definition like this: 
```python3
class Prompt(TypedDict):
    thougt: str = "what you thought"
    eliminate: bool = "whether to eliminate a player or not"
```
