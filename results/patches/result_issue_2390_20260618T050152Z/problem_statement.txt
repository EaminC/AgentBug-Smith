### Current behavior 😯

AutoGPT doesn't check the host OS on startup and tries to execute Linux bash commands on a Windows machine. That includes using the wrong path separator (as reported in issue #2257). In doing so it's unable to create nested subfolders ('projectname\data') and at times but not always, unable to save python files with the correct line termination.

Example line below:
