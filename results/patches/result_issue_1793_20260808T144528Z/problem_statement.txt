# Issue #1793: feat(agent-team): copy the permission rules when creating agent team members

**Background**

Within the agent service (`agentscope.app`), an agent can create team members via the `AgentCreate` tool. However, the sub-agent's permission context is currently empty by default. It should inherit the permission rules from the team leader to avoid redundant user confirmations.

**Changes**

- When creating a sub-agent via `AgentCreate`, copy the permission rules from the team leader and apply it to the newly created sub-agent.
- A possible approach: set `is_state_injected=True` in the `AgentCreate` tool so that it has access to the leader's state, then copy the permission rules from it.
