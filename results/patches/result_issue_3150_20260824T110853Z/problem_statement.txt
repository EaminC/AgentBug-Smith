## What needs to be migrated
Python already has the middleware **core** (`MiddlewareStage`, phases, `MiddlewareRegistry`, `MiddlewareResult`, `InvokeModelStage`) in `strands-py/src/strands/_middleware/`. Its README states the gap: *"Only `InvokeModelStage` is implemented. `ExecuteToolStage` and `AgentStreamStage` will be added as needed."* This ports the two remaining stages **and** the middleware-initiated interrupt path.

- **`ExecuteToolStage`** (`stages.ts:161`) — wraps a single tool execution. Context `ExecuteToolContext` (`stages.ts:104`): `{agent, tool: Tool|undefined, toolUse, invocationState}` + extends `MiddlewareInterruptible`. Result `{result: ToolResultBlock}`. Supports short-circuit (return a mock result without calling `next` → real tool doesn't run); hooks (`BeforeToolCallEvent`/`AfterToolCallEvent`) fire **outside** middleware even on short-circuit.
- **`AgentStreamStage`** (`stages.ts:170`) — wraps the whole agent output stream (outermost). Context `{agent, args, options}` + `MiddlewareInterruptible`. Marked `@internal` in TS (not in public `index.ts`) — keep it internal in Python too.
- **Middleware interrupt path** — `MiddlewareInterruptResult<T> = {response: T}` wrapper; `MiddlewareInterruptible.interrupt()`; `createMiddlewareInterrupt(interruptState, idPrefix)` factory (`agent.ts:368`), a **non-mutating** interrupt fn: id = `` `${idPrefix}:${name}` ``; returns stored response on resume; honors preemptive `response`; else throws `InterruptError` with `source:'middleware'`.

## Python landing points
- Stages → `strands-py/src/strands/_middleware/stages.py` (today only `InvokeModelStage`); export public ones from `_middleware/__init__.py`, keep `AgentStreamStage` internal.
- `ExecuteToolStage` wiring → wrap the **core execution** segment of `ToolExecutor._stream` (`tools/executors/_executor.py:225-249`, the `selected_tool.stream(...)` region) so `Before/AfterToolCallEvent` hooks stay outside middleware.
- `AgentStreamStage` wiring → wrap the per-invocation event-loop-cycle stream in `agent/agent.py` (`_run_loop` ~`1227`), hooks outside. `self._middleware_registry` already exists (`agent.py:407`).
- Interrupt path → reuse `strands-py/src/strands/interrupt.py` (`Interrupt`, `InterruptException`, `_InterruptState`) + `types/interrupt.py` `_Interruptible`; add a `create_middleware_interrupt` factory returning the **wrapper** result (not the raw response).

## Gotchas / open questions (need maintainer input)
- **Generator return values.** Python async generators can't `return` a value; Python already uses the *"last yielded event is the result"* convention for `InvokeModelStage` (`event_loop.py:548`, `registry.py:83`). The two new stages must adopt it — pick the concrete terminal event types.
- **`Interrupt.source` field is missing in Python** (`interrupt.py:22`). Porting `source:'middleware'` means adding a `source` field + serialization — a cross-cutting change.
- **Python interrupts are tool-only today** (`event_loop.py:282`, resume keyed on tool_use/tool_results). An `AgentStreamStage` interrupt doesn't fit that resume shape — expect to extend `_InterruptState.resume()`. **Deepest risk.**
- **No public `addMiddleware` in Python** (TS has `Agent.addMiddleware`). The new stages are unusable without a registration entry point — decide whether this port also adds one.
