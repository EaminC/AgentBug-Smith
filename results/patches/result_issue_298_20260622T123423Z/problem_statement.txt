# Issue #298: [feature] add mem0 memory

Mem0 provides sota retrieval and memory capabilities. It enables **long-term retention** of prior knowledge and debugging experiences.

This issue proposes support the historical debugging & programming experimence (could be structured) memorized into mem0. Relying on the mem0 rehearsal ability, we can enhance the mle-agent planing and programming in new task sessions continuously:

1. `mle integrate` will allow users to optionally provide their own Mem0 API tokens. If no token is provided, the community version will be used by default.

2. Supply some out-of-box APIs within interacting with Mem0. It will support extended metadata injection during `add`/`update` operations, which can help LLM decision-making (ref: https://docs.mem0.ai/core-concepts/memory-operations/update#use-cases).

```python
class Mem0:

    def add(self, content: object | str, metadata: dict[str, str]):
        """
        Adds content to memory. Content can be non-text (e.g., debug/programming sessions).
        Args:
          - content: the item to be memorized
          - metadata: additional context or tags to guide mem0 LLM retrieval
        """

    def query(self, content: str, limit_size: int = 5, fast_query: bool = False) -> list[str]:
        """
        Retrieves relevant memories based on a query.
        Args:
          - content: input query text
          - limit_size: max number of results
          - fast_query: uses vector DB with consolidated memory for faster response
        """

    def evict(self, conditions: list):
        """
        Removes stale or redundant memories based on user-defined conditions.
        """

    def mem_consolidation(self, prompts: list):
        """
        Consolidates structured memories from Graph DB into vector DB to boost retrieval performance.
        """
