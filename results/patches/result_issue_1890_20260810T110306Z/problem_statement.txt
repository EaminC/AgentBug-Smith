# Issue #1890: feat(agent-team): support to expose the subagent hitl events to the leader's session

**Background**

The team leader and its subagents run in separate sessions. As a result, API-based users connected to the leader's session are unable to receive HITL (Human-in-the-Loop) events triggered within subagent sessions.

**Changes**

- Propagate subagent HITL events to the leader's session, making them visible to connected API users
- Forward user confirmation signals back to the originating subagent's session
